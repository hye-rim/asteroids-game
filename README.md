# 아스테로이드 ☄️

추억의 오락실 아스테로이드(Atari, 1979)를 본뜬 혼자 하는 게임입니다. 서버 없이 `index.html` 만 열면 돌아갑니다.

- 조작(PC): **← →** 회전, **↑** 추진, **스페이스** 발사, **↓/H** 순간이동, `P` 일시정지, `M` 소리.
- 조작(폰): 왼쪽 ◀ ▶ 회전, 파랑 추진, 빨강 발사, 보라 순간이동.
- 규칙은 `logic.js`(DOM 없음), 화면·소리·입력은 `game.js`. 시험: `node --test`.

## 규칙
- 선으로 그린 화면이고, **화면 끝은 반대쪽과 이어져 있습니다**(우주선·소행성·총알·UFO 모두).
- 우주선은 돌리고 밀면 보는 방향으로 가속되며, 손을 떼도 천천히 미끄러집니다. 총알은 한 번에 4발까지, 잠시 날다 사라집니다.
- 소행성: 큰 것(20점) → 쏘면 중간 둘(50점) → 쏘면 작은 둘(100점). 작을수록 빠릅니다. 첫 웨이브는 큰 소행성 4개이고 웨이브마다 2개씩 늘어 11개까지입니다.
- UFO: 큰 UFO(200점)는 아무 방향으로 쏘고, 작은 UFO(1000점)는 나를 조준하며 점수가 높을수록 더 정확합니다. 4만 점부터는 작은 UFO만 나옵니다. UFO 는 소행성에 부딪혀도 사라지고(점수 없음), UFO 총알도 소행성을 부수지만 점수는 없습니다.
- 순간이동: 아무 곳으로 가는데 소행성이 많을수록 사고(파괴) 확률이 높습니다.
- 우주선 3대로 시작해 1만 점마다 한 대씩 늘어납니다. 죽으면 가운데가 비었을 때 새 우주선이 나오고 잠깐 보호됩니다.
- 소행성이 줄수록 박동 소리가 빨라집니다.

## 참고한 것과 확인하지 못한 값
- 공개 자료([arcade-history](https://www.arcade-history.com/?n=asteroids-upright-model&page=detail&id=126), [Wikipedia](https://en.wikipedia.org/wiki/Asteroids_(video_game)))에서 확인: 소행성 20·50·100점, UFO 200·1000점, 1만 점마다 추가 우주선, 순간이동은 위험, 모두 부수면 더 많은 큰 소행성이 나옴, 작은 UFO 의 정확도.
- 자료가 서로 다르거나 찾지 못해 제가 정한 값: 시작 우주선 3대, 총알 4발 제한(원작과 같다고 알고 있으나 확인하지 못함), 회전·추진·감속·최고 속도, 총알 속도와 사거리, 소행성 크기와 속도, 웨이브마다 늘어나는 수(4→11)의 정확한 표, UFO 등장 간격, 작은 UFO 가 나오는 확률(4만 점부터 전부 작은 UFO 는 Wikipedia 설명), 순간이동 실패 확률, 보호 시간. 원작의 화면 크기와 회전 단계(원작은 한 번에 몇 도씩)는 따르지 않고 부드럽게 돌립니다.
- 그림·소리는 직접 그린/합성한 것입니다.
